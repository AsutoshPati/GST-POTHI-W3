GST POTHI W3 is a coursework simulation — no real cryptocurrency, GSTIN, or tax filing is involved. Wallet signing uses real ECDSA cryptography to demonstrate how a signed, dual-party invoice resists forgery. Private keys are shown in-browser purely so this demo can sign transactions without a wallet extension — a production system would never do this.
